日本語

Reaxt は、上位版の RPoRea に含まれています。RPoRea を1か所に入れれば、Reaxt もそのまま使えます。

これは RPoRea の動きを試せる、小さなサーバーです。起動すると、あなたの PC の http://127.0.0.1:8768/ に「Hello」のページが出ます。

Windows 版(.exe)をダウンロード 最新版を見る(GitHub)

rporea-hello-windows-x86_64.exe v0.0.1 · SHA-256: 08c1f6ce673a0138f407ce93168ea25255f316dcd815c2d4e36e361882db43c5

  1. 上のボタンで .exe をダウンロードする。
  2. ダブルクリックで起動する(黒い画面が出ます)。
  3. ブラウザで http://127.0.0.1:8768/ を開く。
  4. 止めるときは黒い画面を閉じる(または Ctrl+C)。

インストーラーではありません。あなたの PC の中だけで動き、外からは見えません。署名がないので、Windows が警告したら「詳細情報」→「実行」を選びます。Mac や Linux 版は今後です。

Reaxt is included in RPoRea, the upper edition. Install RPoRea once and you can use Reaxt as well.
